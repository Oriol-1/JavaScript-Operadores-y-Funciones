📋 Tabla de Operadores en JavaScript

¿Qué es un operador? Es un símbolo que le dice a JavaScript qué operación debe realizar entre uno o más valores.

Símbolo Tipo Nombre Descripción Ejemplo
+ Aritmético Suma Suma dos números o concatena strings 5 + 3 → 8
"Hola" + " Mundo" → "Hola Mundo"
- Aritmético Resta Resta el segundo número del primero 10 - 3 → 7
* Aritmético Multiplicación Multiplica dos números 4 * 5 → 20
/ Aritmético División Divide el primer número entre el segundo 20 / 4 → 5
% Aritmético Módulo Devuelve el residuo de una división 10 % 3 → 1
** Aritmético Exponenciación Eleva el primer número a la potencia del segundo 2 ** 3 → 8
++ Aritmético Incremento Aumenta el valor en 1 let x = 5; x++ → x = 6
-- Aritmético Decremento Disminuye el valor en 1 let y = 5; y-- → y = 4
= Asignación Asignación Asigna un valor a una variable let x = 10;
+= Asignación Suma y asigna Suma y luego asigna el resultado let x = 5; x += 3 → x = 8
-= Asignación Resta y asigna Resta y luego asigna el resultado let x = 10; x -= 3 → x = 7
*= Asignación Multiplica y asigna Multiplica y luego asigna el resultado let x = 5; x *= 2 → x = 10
/= Asignación Divide y asigna Divide y luego asigna el resultado let x = 10; x /= 2 → x = 5
%= Asignación Módulo y asigna Calcula módulo y luego asigna let x = 10; x %= 3 → x = 1
== Comparación Igualdad débil Compara valores (convierte tipos si es necesario) 5 == "5" → true
=== Comparación Igualdad estricta Compara valor y tipo (sin conversión) 5 === "5" → false
!= Comparación Desigualdad débil Verifica si no son iguales (débil) 5 != "5" → false
!== Comparación Desigualdad estricta Verifica si no son iguales (estricto) 5 !== "5" → true
< Comparación Menor que Verifica si el primero es menor 3 < 5 → true
> Comparación Mayor que Verifica si el primero es mayor 5 > 3 → true
<= Comparación Menor o igual Verifica si es menor o igual 5 <= 5 → true
>= Comparación Mayor o igual Verifica si es mayor o igual 5 >= 5 → true
&& Lógico AND (Y) Devuelve true si ambas condiciones son verdaderas true && true → true
|| Lógico OR (O) Devuelve true si al menos una condición es verdadera true || false → true
! Lógico NOT (NO) Invierte el valor booleano !true → false
?: Condicional Operador ternario Devuelve uno de dos valores según una condición 5 > 3 ? "Sí" : "No" → "Sí"
. Acceso Punto (acceso a propiedad) Accede a propiedades de un objeto obj.nombre → valor de la propiedad
[] Acceso Corchetes (índice/clave) Accede a elementos por índice o clave arr[0] → primer elemento
typeof Operador Tipo de dato Devuelve el tipo de una variable typeof 5 → "number"
💡 Notas clave sobre operadores:
  • = asigna un valor. NO compara.
  • == compara valores permitiendo conversión de tipo.
  • === compara valor y tipo (es el recomendado en la práctica).
  • && solo es false cuando alguna condición es falsa.
  • || solo es false cuando todas las condiciones son falsas.

1️⃣ Función Básica - Conceptos Fundamentales

¿Qué es una función? Es un bloque de código reutilizable que realiza una tarea específica cuando la llamamos.

Sintaxis básica:
function nombreFuncion() { // Código que se ejecuta } nombreFuncion(); // Llamar la función
✅ Puntos clave de una función:
  • Nombre: cómo la vas a llamar (por ejemplo, sumar).
  • Parámetros: variables entre paréntesis al definirla (ej: a, b).
  • Argumentos: valores reales que pasas al llamar (5, 3).
  • return: indica qué valor devuelve la función al terminar.
Ejemplo: Función con parámetros y retorno
function sumar(a, b) { return a + b; } let resultado = sumar(5, 3); console.log(resultado); // Salida: 8
🧠 Paso a paso:
  • Definimos la función sumar(a, b).
  • Dentro, usamos return a + b para devolver la suma.
  • La llamamos con sumar(5, 3), y eso devuelve 8.
  • Guardamos el resultado en resultado y lo mostramos con console.log.

2️⃣ Recorriendo Arrays con Funciones

Métodos comunes: forEach, map, filter, reduce, find

📌 Idea general: Estos métodos reciben una función de callback (normalmente una función flecha) que se ejecuta para cada elemento del array.
forEach - Recorrer cada elemento:
const numeros = [1, 2, 3, 4]; // .forEach() ejecuta la función una vez por cada elemento. numeros.forEach(num => { console.log(num * 2); // Imprime el doble de cada número }); // Salida en consola: 2, 4, 6, 8
forEach:
  • Qué hace: recorre el array y ejecuta una función por cada elemento.
  • Qué recibe: una función con hasta 3 parámetros: (valor, índice, array).
  • Qué devuelve: nada (undefined). Se usa para efectos secundarios (logs, DOM...).
map - Transformar elementos:
const numeros = [1, 2, 3]; // .map() crea un NUEVO array con los resultados de la función. const duplicados = numeros.map(num => num * 2); console.log(duplicados); // [2, 4, 6] (Array original intacto)
map:
  • Qué hace: crea un nuevo array transformando cada elemento.
  • Qué recibe: una función con (valor, índice, array).
  • Qué devuelve: un array nuevo con los valores transformados.
filter - Filtrar elementos:
const numeros = [1, 2, 3, 4, 5]; // .filter() crea un NUEVO array solo con los elementos que cumplen la condición. const pares = numeros.filter(num => num % 2 === 0); console.log(pares); // [2, 4] (Solo los pares)
filter:
  • Qué hace: se queda solo con los elementos que cumplan la condición.
  • Qué recibe: una función que devuelve true (lo deja) o false (lo descarta).
  • Qué devuelve: un nuevo array con los elementos que pasaron el filtro.
reduce - Acumular valores:
const numeros = [1, 2, 3, 4]; // .reduce() reduce el array a un único valor acumulado. const suma = numeros.reduce((acum, num) => acum + num, 0); console.log(suma); // 10 (1+2+3+4)
reduce:
  • Qué hace: combina todos los elementos en un único valor (suma, producto, objeto, etc.).
  • Qué recibe: una función (acumulador, valorActual) y un valor inicial (ej: 0).
  • Qué devuelve: el valor final acumulado.
find - Encontrar un elemento:
const usuarios = [ { id: 1, nombre: "Ana" }, { id: 2, nombre: "Juan" } ]; // .find() devuelve el PRIMER elemento que cumple la condición. const usuario = usuarios.find(u => u.id === 2); console.log(usuario.nombre); // "Juan" (Accedemos a la propiedad nombre)
find:
  • Qué hace: busca el primer elemento que cumpla la condición.
  • Qué recibe: una función que devuelve true cuando encuentra lo que quieres.
  • Qué devuelve: el elemento encontrado o undefined si no hay coincidencias.

🧮 Ejercicios de operadores

Ejercicio 1 – Operadores aritméticos y de asignación

Escribe código que:

  • Declare una variable total con valor inicial 10.
  • Le sume 5 usando +=.
  • La multiplique por 2 usando *=.
  • Finalmente muestre el resultado por consola.
Ver solución explicada
let total = 10; // Paso 1: total vale 10 total += 5; // Paso 2: total = total + 5 → 15 total *= 2; // Paso 3: total = total * 2 → 30 console.log(total); // Paso 4: muestra 30
Explicación:
  • total += 5 es azúcar sintáctico de total = total + 5.
  • total *= 2 equivale a total = total * 2.
  • Estamos usando operadores de asignación compuesta para escribir menos código y más legible.
Ejercicio 2 – Comparación estricta vs débil

Sin ejecutar el código, intenta adivinar el resultado de cada comparación:

console.log(5 == "5"); // ¿Iguales en valor? console.log(5 === "5"); // ¿Iguales en valor Y tipo? console.log("0" == false); // Conversión implícita console.log("0" === false); // Sin conversión
Ver solución explicada
Resultado:
  • 5 == "5" → true
  • 5 === "5" → false
  • "0" == false → true (por conversión de tipo)
  • "0" === false → false
Explicación:
  • == intenta convertir los valores al mismo tipo antes de comparar: "5" se convierte a número 5, por eso 5 == "5" es true.
  • === no convierte tipos. Compara tipo y valor: número 5 vs string "5" → tipos distintos → false.
  • En "0" == false, ambos se convierten a número: "0" → 0, false → 0 → son iguales → true.
  • En "0" === false no hay conversión de tipo: string vs boolean → siempre false.

🧠 Ejercicios de funciones

Ejercicio 3 – Función con parámetros y return

Crea una función llamada calcularDescuento que:

  • Reciba dos parámetros: precio y porcentaje.
  • Calcule el precio final aplicando el descuento.
  • Devuelva el precio final.
  • Prueba la función con un precio de 100 y un descuento del 20%.
Ver solución explicada
function calcularDescuento(precio, porcentaje) { // precio y porcentaje son parámetros (variables locales) const descuento = precio * (porcentaje / 100); const precioFinal = precio - descuento; return precioFinal; // Devuelve el resultado al exterior } const resultado = calcularDescuento(100, 20); console.log(resultado); // 80
Explicación:
  • Calculamos el valor del descuento con precio * (porcentaje / 100).
  • Restamos el descuento al precio original: precio - descuento.
  • return precioFinal devuelve el valor a quien llame a la función.
  • Al llamar calcularDescuento(100, 20), devuelve 80.
Ejercicio 4 – Función que prepara un mensaje

Crea una función llamada saludarUsuario que:

  • Reciba un nombre (nombre) y una edad (edad).
  • Devuelva un string del tipo: "Hola Ana, tienes 25 años".
  • Muestra el resultado en consola para comprobarlo.
Ver solución explicada
function saludarUsuario(nombre, edad) { // Concatenamos strings con variables usando + return "Hola " + nombre + ", tienes " + edad + " años"; } const mensaje = saludarUsuario("Ana", 25); console.log(mensaje); // "Hola Ana, tienes 25 años"
Explicación:
  • La función no sabe qué nombre ni edad tendrá: lo recibe como parámetros.
  • Concatenamos partes del mensaje usando + y devolvemos el string completo.
  • Quien llama a la función obtiene el texto y lo puede usar, por ejemplo, en un console.log.

📚 Ejercicios con arrays y sus métodos

Ejercicio 5 – Usar map para transformar

Tienes un array de precios sin IVA:

const precios = [10, 20, 30];

Usando map, crea un nuevo array llamado preciosConIVA donde cada elemento tenga un 21% de IVA añadido.

Ver solución explicada
const precios = [10, 20, 30]; // .map() transforma cada precio multiplicándolo por 1.21 const preciosConIVA = precios.map(precio => precio * 1.21); console.log(preciosConIVA); // [12.1, 24.2, 36.3]
Explicación:
  • Multiplicamos cada precio por 1.21 (100% + 21% de IVA).
  • map crea un nuevo array con el resultado de la función para cada elemento.
  • El array original precios no se modifica.
Ejercicio 6 – Filtrar valores

Dado el siguiente array:

const edades = [12, 18, 25, 16, 40];

Usando filter, crea un nuevo array mayoresDeEdad con las edades mayores o iguales a 18.

Ver solución explicada
const edades = [12, 18, 25, 16, 40]; // .filter() mantiene solo los que cumplen edad >= 18 const mayoresDeEdad = edades.filter(edad => edad >= 18); console.log(mayoresDeEdad); // [18, 25, 40]
Explicación:
  • La condición edad >= 18 devuelve true para 18, 25 y 40.
  • filter construye un nuevo array solo con los elementos que cumplen la condición.
  • Los valores 12 y 16 quedan fuera porque no cumplen >= 18.
Ejercicio 7 – Sumar todos los elementos con reduce

Dado:

const numeros = [3, 7, 2];

Usa reduce para obtener la suma total de los números.

Ver solución explicada
const numeros = [3, 7, 2]; // .reduce() suma acumulativamente. 0 es el valor inicial. const sumaTotal = numeros.reduce((acum, num) => acum + num, 0); console.log(sumaTotal); // 12
Explicación paso a paso:
  • Valor inicial del acumulador: 0.
  • Iteración 1: acum = 0, num = 3 → acum + num = 3.
  • Iteración 2: acum = 3, num = 7 → 3 + 7 = 10.
  • Iteración 3: acum = 10, num = 2 → 10 + 2 = 12.
  • Resultado final devuelto por reduce: 12.
Ejercicio 8 – Buscar con find

Dado el siguiente array de objetos:

const productos = [ { id: 1, nombre: "Teclado", precio: 25 }, { id: 2, nombre: "Ratón", precio: 15 }, { id: 3, nombre: "Monitor", precio: 120 } ];

Usa find para buscar el producto cuyo id sea 2 y muestra su nombre por consola.

Ver solución explicada
const productos = [ { id: 1, nombre: "Teclado", precio: 25 }, { id: 2, nombre: "Ratón", precio: 15 }, { id: 3, nombre: "Monitor", precio: 120 } ]; // .find() busca el objeto donde la propiedad id sea 2 const productoEncontrado = productos.find(p => p.id === 2); // Accedemos a la propiedad .nombre del objeto encontrado console.log(productoEncontrado.nombre); // "Ratón"
Explicación:
  • find recorre el array hasta que la condición p.id === 2 devuelve true.
  • Devuelve directamente el objeto que cumple la condición.
  • Luego accedemos a su propiedad nombre con productoEncontrado.nombre.
